# Rights for the corrected MOONKATTY NEWS edition

Checked 20 October 2026. A still is in the corrected MP4s only when `media-automation` `classify()` accepts the license and `layoutFor` accepts the file for both 1920×1080 and 1080×1920.

The edition is `news-launch/artifacts/corrected-episode/`. It was rendered by `NewsVideoFactory` (`factory2.js`). Generated color cards are not used. `imageRights: 'generated'` is not set.

On-screen credit tags and `image-licenses.json` use the attribution line their library built. The Abuja still is share-alike. This edition is not published. A later publish has to keep that CC BY-SA obligation, which their license policy already allows.

`classify()` accepts UK OGL v3 (`OGL-UK-3.0`, attribution required). The in-flight RAF Typhoon file on Commons is OGL 2, so it stays rejected and is not in the video. The frame that is encoded is the CC BY 4.0 photograph above. A photo titled as Alberta separatists was skipped so the frame would not imply a result. Elections Alberta has not called a winner.

## Graphics drawn by the factory

Intro, lower-thirds, credits, and outro are SVG rendered with `rsvg-convert` from `media-automation/src/video/graphics.js`, plus `media-automation/assets/moonkatty-logo.svg`. Those overlays are original to that module. The starfield behind the title cards is generated by ffmpeg in `makeStarfield`. No third-party photograph is in those cards.
