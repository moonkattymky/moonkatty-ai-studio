# Reference clip

File: `osr-us-male-0030-12s.wav`

Source file: `OSR_us_000_0030_8k.wav` from the Open Speech Repository, American English table, row marked M, 16-bit PCM, 8 kHz, Harvard sentences.

Page: https://www.voiptroubleshooter.com/open_speech/american.html

Conditions, from https://www.voiptroubleshooter.com/open_speech/index.html : the files may be copied and used without restriction, including research and marketing. Attribution requested as "Open Speech Repository".

This clip is the first 12 seconds of that file, converted to 24 kHz mono PCM so a cloner has a single short prompt. The original bandwidth is still 8 kHz. No celebrity and no private recording is in this clip.

LibriVox reader Mark Nelson (catalog https://librivox.org/reader/251, The Time Machine version 3) is public domain in the USA according to the LibriVox banner. That catalog page does not state sex or country, so his recording was not used as the clone prompt.
