### TikTok

- Адаптер есть, в `lib/publish-desk.js` и во вкладку соцсетей не подключён.
- Content Posting API: публичная прямая публикация требует аудит приложения. Без аудита — только приватные ролики `SELF_ONLY` (так уже записано в `docs/media-automation/PLATFORM_CONSTRAINTS.md` и в адаптере).
- Нужны приложение на developers.tiktok.com и согласия пользователя. Для проверки личности и права постить официально используются Login Kit и вызовы вроде user info и `creator_info/query`. Типичные scope: `user.info.basic`, `video.publish` (прямая публикация), `video.upload` (черновик во входящие). Без аудита и без живого ответа API статус «Подключено» ставить нельзя.
- Нативного планирования у API нет (`capabilities.js`).

### X

- Адаптер есть, в стол не подключён. В обычном наборе адаптеров он выключен флагом experimental.
- Постинг API v2 с пользовательским контекстом: OAuth 2.0 PKCE, scope не меньше `tweet.read`, `tweet.write`, `users.read`, `offline.access`; медиа — `media.write`. Проверка подключения — `GET /2/users/me`, не факт поста.
- Практическая запись упирается в тариф. В `docs/media-automation/PLATFORM_CONSTRAINTS.md` зафиксировано: бесплатный уровень — порядка 500 постов в месяц, только запись, на всё приложение; Basic — около $200 в месяц. Цифры нужно сверить на developer.x.com перед оплатой: прайс меняется. Без оплаченного доступа с нужными scope живая отправка невозможна, и в этом коммите она не включалась.

### Instagram

- Каркас стола по схеме Telegram/YouTube не сделан.
- Профессиональный аккаунт (Business или Creator). Для Facebook Login: страница, к которой привязан Instagram. Личный аккаунт API не публикует.
- Scope для своего контента (Facebook Login): `instagram_basic`, `instagram_content_publish`, `pages_read_engagement`. Чужие аккаунты — Advanced Access: App Review и проверка бизнеса.
- Публикация Reels в адаптере ждёт публичный HTTPS `video_url`. Прямой локальный файл этой схемой не закрыт.
- Нативного `scheduled_publish_time` у Instagram нет.
- Существующий OAuth в `meta.js` кладёт токен в SQLite и в TEST выключен. Для стола он не годится, пока секрет не окажется только в Keychain и пока нет живой проверки Graph.

### Facebook

- Каркас стола не сделан.
- Нужна Страница и право создавать контент. Личный профиль через API не публикуется. Может понадобиться Page Publishing Authorization.
- Scope: `pages_show_list`, `pages_read_engagement`, `pages_manage_posts` (видео ещё `publish_video`). Чужие Страницы — App Review и Advanced Access.
- Тот же блокер `meta.js`: в TEST публикация выключена, токены не в Keychain стола, живой проверки в этом этапе не было.
