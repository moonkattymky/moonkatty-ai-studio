## Behaviour
- `MasterVoice.createTTS()` is the default TTS for `bin/news2.js` and `bin/orchestrate.js`. It verifies model **and** voices hashes and **throws** ("Refusing to substitute another voice") if anything is missing or different — no fallback to Piper/espeak/another Kokoro voice.
- A locked config with `autoReplace !== false` is rejected. Changing the voice requires `unlock(by, reason)` (audit trail) by the owner.
- One voice for all stories and all 7 emotion modes.
- `/workspace/ma-out/voice-casting-v2/casting.json`: `pinned: true`, `pinnedVariant: "B"`; A and C are `pinned: false`.

## Studio 5 shared-library export
`docs/media-automation/exports/master-voice.studio5.json` is generated by `MasterVoice#exportForStudio5()` (schema `moonkatty.studio5.voice-profile/v1`, a **proposal** — Studio 5's library format was not available to us; nothing was written into other bots' code). Studio 5 should:
1. import the record, ship `kokoro-v1.0.onnx` + `voices-v1.0.bin` and verify both sha256 values,
2. reproduce the blend as `sum(style[v] * w)` and the +0.4 st post-shift exactly,
3. return its `voiceProfileId`, which we then put into `master-voice.json` (`voiceProfileId`, currently `null`).
