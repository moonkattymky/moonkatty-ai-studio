# Подключение Facebook и Instagram (Meta) к MOONKATTY AI STUDIO

Модуль «Соцсети → Страницы FB / IG» работает только через официальный Meta Graph API (OAuth на сервере на Mac). Пока страницы не подключены, везде показано «Не подключено», публикация отключена с указанием причины. Успех никогда не имитируется.

Четыре рабочих пространства:

| Пространство | Платформа | Назначение |
|---|---|---|
| MOONKATTY NEWS — Facebook | Facebook Page | новости на английском, US/CA/UK/AU |
| MOONKATTY NEWS — Instagram | Instagram Professional | новости, Reels, Stories, карусели |
| MOONKATTY — Facebook | Facebook Page | игра, обновления, трейлеры, бренд |
| MOONKATTY — Instagram | Instagram Professional | игра, Reels, бренд |

## 1. Создание страниц Facebook

1. Войдите в личный профиль Facebook (страница всегда принадлежит профилю/Business-портфолио).
2. Откройте https://www.facebook.com/pages/create (кнопка «+ Создать страницу» в студии открывает именно этот адрес).
3. Создайте две страницы: `MOONKATTY NEWS` (категория, например, «Новости и СМИ») и `MOONKATTY` (например, «Видеоигра»).
4. Рекомендуется добавить обе страницы в Business-портфолио: https://business.facebook.com → Настройки → Аккаунты → Страницы.

## 2. Профессиональные аккаунты Instagram и привязка

1. Создайте два аккаунта Instagram (https://www.instagram.com/accounts/emailsignup/).
2. В приложении Instagram: Настройки → «Тип аккаунта и инструменты» → «Переключиться на профессиональный аккаунт» → «Автор» или «Бизнес». Публикация через API доступна для обоих типов.
3. Привяжите каждый аккаунт к своей странице Facebook: в Meta Business Suite → Настройки → Аккаунты Instagram → «Подключить», либо в настройках страницы Facebook → «Связанные аккаунты» → Instagram.
4. Проверка: при подключении IG-пространства студия ищет у выбранной страницы поле `instagram_business_account`. Если его нет — выводится ошибка «К этой странице не привязан профессиональный аккаунт Instagram».

## 3. Создание Meta-приложения

1. Зарегистрируйтесь как разработчик: https://developers.facebook.com/ → «Начать».
2. «Мои приложения» → «Создать приложение» → сценарий (use case) «Управление всем на вашей странице» и/или «Управление сообщениями и контентом в Instagram» (тип Business). Привяжите приложение к Business-портфолио.
3. Добавьте продукт **Facebook Login for Business**. В нём:
   - «Valid OAuth Redirect URIs»: адрес вашего сервера + `/api/meta/oauth/callback`, например `https://<имя-mac>.<tailnet>.ts.net/api/meta/oauth/callback`. Meta требует HTTPS — удобнее всего `tailscale serve --bg 8787` (см. docs/CONNECT_MAC.md); адрес `http://localhost:8787/...` работает только для тестов на самом Mac.
   - (Опционально) создайте «Конфигурацию» с нужными разрешениями и скопируйте её **Configuration ID** — тогда студия запросит разрешения по `config_id`, а не по списку `scope`.
4. «Настройки приложения → Основное»: скопируйте **App ID** и **App Secret**.
5. Введите их в студии: «Настройки → Meta-приложение» (секрет шифруется AES-256-GCM и не возвращается в браузер) или через переменные окружения на Mac:

```bash
export META_APP_ID=...
export META_APP_SECRET=...
export META_REDIRECT_URI=https://<имя-mac>.<tailnet>.ts.net/api/meta/oauth/callback
export META_CONFIG_ID=...          # опционально
export META_GRAPH_VERSION=v26.0    # по умолчанию v26.0
export STUDIO_SECRET_KEY=...       # опционально; иначе ключ создаётся в data/secret.key (0600)
```

Никогда не коммитьте эти значения в репозиторий.

## 4. Подключение в студии

1. «Соцсети → Страницы FB / IG» → выберите пространство → «Подключить через Facebook».
2. В окне Meta отметьте нужные страницы (и связанные аккаунты Instagram) и выдайте разрешения.
3. Вернувшись в студию, выберите страницу для пространства. Токен страницы сохраняется на сервере в зашифрованном виде.
4. Нажмите «Проверить права» — студия вызывает `me/permissions` и `debug_token`, показывает недостающие разрешения, срок действия токена и использование лимитов (`X-App-Usage`, `X-Business-Use-Case-Usage`).
5. «Отключить» удаляет токены с сервера. Полностью отозвать доступ: Facebook → Настройки → «Бизнес-интеграции» → удалить приложение.

## 5. Необходимые разрешения (Graph API v26.0)

Facebook Pages:

| Разрешение | Зачем |
|---|---|
| `pages_show_list` | список страниц для выбора |
| `pages_read_engagement` | данные страницы, подписчики, посты |
| `pages_manage_posts` | публикация постов, фото, видео |
| `read_insights` | статистика страницы |
| `pages_read_user_content` | чтение комментариев |
| `pages_manage_engagement` | ответы на комментарии (только после утверждения) |
| `business_management` | страницы, принадлежащие Business-портфолио |

Instagram (через Facebook Login, аккаунт привязан к странице):

| Разрешение | Зачем |
|---|---|
| `instagram_basic` | профиль и медиа |
| `instagram_content_publish` | публикация фото, Reels, Stories, каруселей |
| `instagram_manage_insights` | статистика, охват, география |
| `instagram_manage_comments` | чтение и ответы на комментарии |

Примечание: при альтернативном способе «Instagram API with Instagram Login» (без страницы Facebook) используются разрешения `instagram_business_basic`, `instagram_business_content_publish`, `instagram_business_manage_insights`, `instagram_business_manage_comments`. Студия использует вариант через Facebook Login, так как он покрывает и страницы, и Instagram одним входом.

Названия разрешений актуальны на октябрь 2026 г.; перед подачей на проверку сверьтесь с https://developers.facebook.com/docs/permissions.

## 6. Режим разработки, App Review и верификация бизнеса

- В режиме **Development** приложение работает только для пользователей с ролью в приложении (администратор/разработчик/тестировщик). Для собственных страниц Игоря этого достаточно: если вы администратор приложения и страниц, App Review не обязателен (Standard Access).
- **Advanced Access** и **App Review** нужны, если приложением будут пользоваться люди без роли в нём. Для проверки понадобятся: скринкаст использования каждого разрешения, описание, политика конфиденциальности (URL) и инструкция по удалению данных.
- **Business Verification** (документы компании в Business-портфолио) требуется для Advanced Access к ряду разрешений, например `business_management` и разрешениям страниц.
- Токены страниц, полученные из долгоживущего пользовательского токена, обычно не истекают, но становятся недействительными при смене пароля, снятии роли или отзыве доступа — тогда нажмите «Переподключить».

## 7. Ограничения платформы

- Instagram: не более 100 публикаций через API за 24 часа на аккаунт (учитываются и карусели); медиа должны быть доступны по публичному HTTPS-адресу (поле «Медиа URL»). Ссылки в подписи не кликабельны.
- Лимиты запросов: Business Use Case rate limits (зависят от вовлечённости страницы). При коде ошибки 4/17/32/613/80001+ студия увеличивает задержку повтора.
- Монетизация (in-stream, Reels, Stars, подписки, брендированный контент) не определяется через API в этой версии — проверяйте её в Professional Dashboard / Meta Business Suite и отмечайте вручную.

## 8. Стоимость

- Meta Graph API, Facebook Login, Instagram API — **бесплатно**. Платные только рекламные кампании (Ads Manager), которые студия не использует.
- Business Verification и App Review — бесплатно.
- Tailscale (личный план) — бесплатно.
