# OpenCode и 3D Studio — тестовая сборка v1.3.0-test

Ветка `fix/opencode-3d-v130`. Рабочий OpenCode на порту 4096 эта правка не запускает и не проверяет.

## Почему «Проверить» писал «Соединение отклонено»

На `127.0.0.1:4097` никто не слушал. Студия сама сервер OpenCode не запускала. Пароль в оболочке не появляется: его нет в переменных Терминала, пока отдельный процесс `opencode serve` не получит его из Keychain только в своё окружение.

## Где лежит пароль в Связке ключей

Тестовая сборка пишет и читает **одну и ту же** запись. Команда — `/usr/bin/security`, не keytar.

| Поле в Связке ключей | Значение |
| --- | --- |
| Служба (service, Where) | `MOONKATTY AI STUDIO.test` |
| Учётная запись (account) | `opencode-server-password` |
| Название (Name) | `MOONKATTY AI STUDIO.test — OpenCode` |

Точка в службе обязательна. Название продукта «MOONKATTY AI STUDIO TEST» — это не служба. Учётная запись — не слово `opencode`. Поиск по этим двум словам запись не находит.

Запись: `security -i`, в stdin строка `add-generic-password -U -s "…" -a "opencode-server-password" -l "…" -X <hex>`. Пароль в аргументы не попадает. Чтение: `find-generic-password -s "…" -a "opencode-server-password" -w`. Проверка «пароль сохранён»: тот же поиск без `-w`.

Рабочая версия — служба `MOONKATTY AI STUDIO` (без `.test`), порт OpenCode 4096. Это другая запись.

## Как запустить OpenCode для теста

1. Откройте тестовое приложение (порт 8687).
2. Настройки → OpenCode — доступ к серверу. URL `http://127.0.0.1:4097`, логин `opencode`. Введите пароль и сохраните. На экране появятся служба и учётная запись.
3. Нажмите **Запустить OpenCode** (та же кнопка есть в 3D Studio → Окружение). Без пароля в Keychain кнопка ничего не запускает.
4. Нажмите **Проверить подключение** в настройках или **Проверить** в 3D Studio. Кнопка в 3D Studio делает реальный запрос и показывает ответ.

Либо в Терминале (окно не закрывать): скрипт `opencode/serve-test.sh` внутри распакованного приложения. Он читает ту же запись Keychain и запускает `opencode serve --hostname 127.0.0.1 --port 4097`. Пароль на экран не выводится.

## Модель

Пустое поле модели — `ollama/qwen3:8b` (и в студии, и в `opencode/opencode-studio.json`). `ollama/qwen2.5-coder:7b` можно выбрать вручную; при контексте Ollama 4096 она часто не возвращает JSON.

## Сцена 3D

Цепочка: Director → агент 3D DESIGN → OpenCode (JSON текстом) → студия пишет `scene_params.json` → Blender сохраняет `.blend` → открывает его снова → PNG → превью.

Если OpenCode не запущен, оборвался по сети, не ответил вовремя, вернул ошибку модели или дважды прислал неверный JSON, студия записывает уже проверенные параметры (в журнале: «Агент OpenCode не записал scene_params.json» и «запасной путь») и продолжает сборку. В задании видны пути к `scene_params.json`, `.blend` и PNG.

Останавливают задание, без запасного файла: неверный пароль (HTTP 401), чужая конфигурация OpenCode, файл, созданный агентом, выполненный запрещённый инструмент, три запроса разрешения, символическая ссылка, негодные запасные параметры.

Нужна новая сборка приложения: кнопка, проверка и запасной путь находятся в коде, а не в одном только файле настроек.
