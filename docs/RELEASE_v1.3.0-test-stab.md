## 1. Память

`lib/host-memory.js` читает память так:

- Darwin: `/usr/bin/vm_stat` с пустым массивом аргументов. Доступно = (Pages free + inactive + speculative + purgeable) × размер страницы. Рядом вызывается `/usr/bin/memory_pressure`.
- Linux: `MemAvailable` из `/proc/meminfo`, килобайты × 1024.
- Иначе `os.freemem()` с подписью `os.freemem без кэша ОС, цифра завышает занятость`.

Подписи источников: `доступно: vm_stat free+inactive+speculative+purgeable` и `доступно: MemAvailable`. Вызов идёт через `execFile`, без оболочки и без `shell: true`. Путь команд фиксированный. Ввода пользователя в команду нет, инъекции команды нет.

Поле `memFree` в `/api/system` остаётся `os.freemem()`. Рядом отдаются `memAvailable`, `memOsFree`, `memSource`, `memLabel`, `memPressureFreePct`. Ошибка снимка оставляет прежние поля. Панель берёт `memAvailable`, а при его отсутствии `memFree`, и печатает `memLabel`. Кэш живого снимка — 15 с. Снимок с подставленными `exec` или `readFile` кэш не занимает.

Проверенные края парсера:

- Точка после числа в выводе Apple учитывается, сумма страниц верная.
- Нет строки размера страницы или размер 0 — это не попадание `vm_stat`, срабатывает запасной путь.
- `MemAvailable: 0` — честный ноль. Нечисловое значение — нет данных, запасной путь.
- Неполная строка `vm_stat` (есть free и размер страницы, нет inactive/speculative/purgeable) всё ещё помечается как формула из четырёх полей, недостающие страницы считаются нулём. У настоящего `vm_stat` эти строки есть. Это остаточная оговорка честности, не отказ.
- Число с запятой тысяч (`12,345`) обрезается до `12`. Apple печатает хвостовую точку, не запятую. Парсер к запятой не готов. Остаточная оговорка, не отказ.

На этой Linux-машине живой `/api/system` после входа отдал `memSource=meminfo`, подпись `доступно: MemAvailable`, и `memAvailable` совпал с байтами `MemAvailable`. Завышение «97%» через один только `os.freemem()` на Linux не воспроизводится: у Node `freemem` здесь уже равен `MemAvailable`. Формула macOS доказана фикстурой набора `test:memory` (97% по `os.freemem` против 51% по `vm_stat`). Сам `vm_stat` на Mac не запускался.

`node-agent/agent.js` по-прежнему считает свою `memAvailable()` отдельно и в этот коммит не входил. При отсутствии строки размера страницы агент подставляет 4096 и может вернуть 0, не переходя к подписи «завышает». Это прежний путь узла, не регрессия панели.
