# Проверка безопасности v1.2.4-test (узлы)

База: `a2a35c8` (v1.2.3-test). Ветка: `feat/v1.2.4-test-nodes`. Источник узлов: `origin/feat/studio-operations` @ `af1e869` (Studio 3). Файлы перенесены, ветка не сливалась. Ветки Studio 3 и `main` не менялись.

## 1. Поверхность сети
| Слушатель | Адрес | Проверка |
|---|---|---|
| Панель | 127.0.0.1:8687 | HOST, отличный от loopback, даёт exit 78. Дополнительный фильтр источника: только loopback и Tailscale, иначе 403. Host и Origin проверяются как раньше. |
| Node API (HTTPS, самоподписанный сертификат, пин SHA-256) | 127.0.0.1:8690 + один адрес Tailscale | Адрес из настроек или `STUDIO_NODES_BIND` проходит `isTailscaleOrLoopback`. 0.0.0.0, `::`, LAN и публичные адреса отклоняются: настройки возвращают 400, при запуске такая привязка не создаётся. Запросы от не-Tailscale и не-loopback источников получают 403. |
| OpenCode | 127.0.0.1:4097 | без изменений |

- Tailscale Serve и Funnel не используются и не включаются. Публичных портов нет.
- В TEST-сборке Node API выключен по умолчанию. Включает его владелец в панели (пароль + СОХРАНИТЬ), изменение действует после перезапуска.
- `isPrivateIPv4` (Studio 3) считает «частными» 10/8, 172.16/12, 192.168/16, 127/8 **и** 100.64/10, то есть Tailscale туда входит. Для привязки этого недостаточно: LAN-адреса тоже проходят. Поэтому слушатель и фильтр источника используют более строгую `isTailscaleOrLoopback`: 127/8, ::1, 100.64.0.0/10, fd7a:115c:a1e0::/48. `isPrivateIPv4` экспортируется без изменений (совместимость с тестами Studio 3).

## 2. Учётные данные узлов
- Токен `nk_<id>.<secret>` возвращается **один раз** при регистрации или смене. На диске (`ops/`) хранится только SHA-256. Тест проверяет, что секрета нет ни в `ops/`, ни в `studio.db`, и что `GET /api/ops/nodes` токены не возвращает.
- Регистрация и смена токена требуют сессию владельца, его пароль и слово ВЫДАТЬ или СМЕНИТЬ. Отзыв требует слово ОТОЗВАТЬ. После смены старый токен получает 401, отозванный тоже отклоняется.
- В TEST-сборке id узла оканчивается на `-test`. Keychain узла: `moonkatty-node-<id>-test`, так что с будущими prod-узлами коллизии нет.
- На узле токен хранится в Keychain. `security add-generic-password … -w` запрашивает его интерактивно, в argv токена нет.
- Одноразовые коды подключения **не реализованы**, для них нужен агент 0.2.1. Это задача на будущее.

## 3. Протокол и задачи
- Принимаются только агенты 0.2.x, остальные получают 426. Обязателен только `Authorization: Bearer`. `hello` и `pull` возвращают `protocol:1`.
- FORBIDDEN_CAPS (Blender, видео, тяжёлые модели, произвольные команды, OpenCode) отклоняются при постановке. Узлам отдаются только light-задачи. `scanSecrets` отклоняет секреты во входных данных.
- Файлы: потоковая запись, лимит 512 МБ (413), несовпадение SHA-256 даёт 422. GET отдаёт файл только для задачи, которую сейчас арендует этот узел.
- Пока занята блокировка тяжёлых операций Mac mini, задачи с файлами не выдаются.

## 4. Прочее (Studio 4)
- `POST /api/comments` больше не создаёт комментарий в статусе approved или replied (сохраняется new). Утверждение остаётся отдельным действием владельца.
- В TEST-сборке нет пункта «Проверить обновления…», `checkUpdates` ничего не делает, обращений к GitHub нет.
- Squirrel.framework **не удалён**: Electron Framework связывает его жёстко (LC_LOAD_DYLIB, не weak), вместе с ReactiveObjC и Mantle. Без них приложение падает при запуске. Автообновление в коде не используется.
- Публикация в TEST отключена, `meta.js` (публикатор) в сборку не входит. Сборка вшита и работает только при целых маркерах (fail-closed), это не менялось.
- Файлы узлов (`lib/ops/*`, `node-agent/`, `scripts/node/`, `test/`, `docs/ops/`) в приложение не входят, кроме `lib/ops/nodes*.js`, `state.js` и `jobs-adapter.js`, которые нужны серверу.

## 5. Не проверено на настоящих Mac
Привязка к реальному адресу Tailscale и запрос брандмауэра macOS. Генерация сертификата LibreSSL `openssl ec`: если она не сработает, есть запасной вариант RSA-2048. Keychain на узлах. Запуск агентов на Ventura и Monterey (пакеты собраны, minos 13.5 и 11.0 прочитаны из Mach-O).
