# System Doctor

Встроенная диагностика MOONKATTY AI STUDIO. Владелец нажимает кнопки в разделе **System Doctor**, Терминал не нужен.

Кнопки: быстрая проверка, полная диагностика, Ollama (`qwen3:8b`), OpenCode только на `127.0.0.1:4097`, Blender, целостность базы, бэкап, перезапуск OpenCode/Ollama, снятие зависшего процесса из списка, проверка восстановления копии, скачивание отчёта.

Команды берутся из фиксированного списка. В аргументы не попадает текст модели. `sudo`, Keychain, Gatekeeper, запись Tailscale и порт **4096** в коде запрещены.

Подтверждение владельца пишется через существующий Approval Center (`request` / `decide`). В `subject_id` лежит SHA-256 параметров (ровно 64 символа — предел схемы). Срок — 10 минут. Пароль владельца спрашивается ещё раз перед выполнением.

На Linux нет `vm_stat`, `pmset`, `codesign`, Keychain и, если пакеты не установлены, Ollama, OpenCode, Blender и Tailscale. Такие пункты получают статус **BLOCKED**, а не выдуманный успех.
