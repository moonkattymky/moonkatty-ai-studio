# Интерфейсы: основная студия и студия 2

Документ описывает границу этой ветки. Схему cues мы не копируем и не заменяем. Авторитетный файл — `media-automation/config/animation-cues.schema.json` на `feat/media-automation`, `$id` `moonkatty/animation-cues/v1`. Он предварительный до стадии D основной студии.

Стороны:

- Основная студия — согласовано.
- Студия 2 — согласовано.

## Профиль голоса

Студия 2 задаёт профиль. Эта ветка хранит его в `si_voice_profiles` и не вызывает синтез.

Идентификатор ведущего: `MOONKATTY_NEWS_MASTER_VOICE`. Пространство: `moonkatty_news`. Импорт экспорта пишет только черновик. `status: locked` из файла студии 2 в базу не кладётся. В таблице допустимы `draft`, `approved`, `superseded`.

Утверждает только владелец, вызовом `voices.approve`. Код сам профиль не утверждает. `executed` остаётся `false`. Повторное утверждение уже утверждённой строки возвращает её и ничего не меняет. Утверждение другого черновика переводит прежний в `superseded`. Снятую строку утвердить снова нельзя.

`mouthScale` задаёт основная студия. Если число есть, допустимый диапазон `0.5`–`2.0`. Пустое значение у незаполненного черновика остаётся. Проверка стоит в `voices.js` и в обеих схемах профиля.

Поля, которые основная студия читает через `voices.forStudio`: `id`, `approved`, `sampleRate`, `recognizer`, `gain`, `mouthScale`, `engine`, `voice`, `speed`, `pitchShift`, `modelSha256`, `voicesSha256`. Пока утверждённой строки нет, чтение завершается отказом.

## Общая память

Три пространства: `moonkatty_news`, `moonkatty_project`, `moonkatty_shared`. Новости и проект друг друга не читают. Общее читают оба. Редакторская роль в схеме есть и выключена: итог ставит владелец.

Мастер-модель кота в реестре — карточка `MOONKATTY_MASTER_CHARACTER` в `moonkatty_shared`. Здесь лежат SHA-256, замок версии, права на референсы и ссылка `voiceProfileId`. Файл `.blend`, риг и сетку эта ветка не создаёт.

`resolveProject` синхронный. Неизвестный id становится `unassigned`, строка не выбрасывается. Голый `moonkatty_shared` — известный id.

## Сигналы мимики

Вход `character_animate` у основной студии: утверждённый `voiceProfileId` и `masterAssetVersion`. Оба обязательны. Версия по умолчанию не подставляется.

`prepareFacialUse` отказывает, если:

- в запросе нет `masterAssetVersion`;
- такого номера нет в реестре;
- эта версия не заблокирована или не утверждена;
- хеш заблокированной версии не совпадает с карточкой модели;
- профиль голоса не утверждён или id в запросе — не тот, что утверждён.

Кадры не считаются. Blender не вызывается. `executed` остаётся `false`. Использование пишется в `moonkatty_news` с `whereUsed: facial_animation`.

Поправки основной студии, принятые:

1. Отказ, если профиль или версия модели не утверждены, и если `masterAssetVersion` не найден. Подстановки нет.
2. `mouthScale` только `0.5`–`2.0`. Диапазон принадлежит основной студии.
3. Тайминги и виземы — строго схема студии 2 `moonkatty/animation-cues/v1`. Своего формата нет.
4. `character_animate` в `jobsApi` ещё нет. Класс задачи — `gpu_heavy`, под тяжёлым замком. Ключ идемпотентности назначает сервер. Код очередей эта ветка не меняет.

## Файл cues студии 2

Имя файла: `<episode>-<preset>.cues.json` рядом с mp4. `preset` — `youtube` или `shorts`.

Верх файла, как студия 2 его согласовала: `{ contract, video, voice, segments }`. `voice` — объект:

```json
{
  "voiceProfileId": "MOONKATTY_NEWS_MASTER_VOICE",
  "modelSha256": "<64 hex>",
  "voicesSha256": "<64 hex>"
}
```

Сегмент, обязательные поля по их схеме: `version` со значением `"1"`, `segmentId`, `audio` (`file`, `sha256`, `durationSec`, `sampleRate` 48000), `text`, `emotion` (`mode`, `intensity` от 0 до 1, `changes` из `{ t, mode }`), `words` (`w`, `start`, `end`, необязательный `stress`). Режимы: `SERIOUS`, `NEUTRAL`, `EXCITED`, `CURIOUS`, `PLAYFUL`, `WITTY`, `EMPATHETIC`. Необязательные дорожки: `visemes` (`t`, `v`), `pauses`, `smile`, `blinks`, `gestures`, `head`, `ears`.

Время — секунды от начала аудио сегмента. `offsetSec` сдвигает сегмент на таймлайне ролика. Рядом лежит `lipsync-handoff.json`: `anchor.wav` (48 кГц, моно) и `voiceProfileId`. Точность меток, которую называет студия 2: ±0.1–0.15 с. Мы её не измеряем.

На `origin/feat/media-automation` @ `477d06a` файл схемы всё ещё описывает один сегмент: в `required` стоят `version`, `segmentId`, `audio`, `text`, `emotion`, `words`. Верхний объект с `voice` — принятая поправка студии 2, в `required` этого файла его ещё нет. До стадии D ориентир — их схема плюс эта поправка. Свою копию схемы мы не заводим.

Наша проверка — `animationCues.assertVoice`. Она читает только `cues.voice` и сверяет `voiceProfileId`, `modelSha256` и `voicesSha256` с утверждённой строкой реестра. Черновик, чужой id, другой хеш, строка вместо объекта и отсутствующий `voice` дают отказ. `executed` остаётся `false`. Сегменты, виземы и тайминги этот вызов не разбирает.
