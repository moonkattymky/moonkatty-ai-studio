# MOONKATTY AI STUDIO для macOS (Apple Silicon)

Настольное приложение «MOONKATTY AI STUDIO.app» — отдельное окно с иконкой в Dock, которое показывает панель **локального сервера на вашем Mac** (`http://127.0.0.1:8787`). Приложение никогда не открывает версию с GitHub Pages: все данные, агенты и расписания работают на Mac.

> Статус: сборка сделана на Linux и **не проверялась на реальном Mac**. Рекомендуемый путь — собрать из исходников (`docs/BUILD_MAC.md`). Безопасность: `docs/SECURITY_AUDIT.md`; подпись Apple: `docs/APPLE_SIGNING.md`; что проверить: `docs/MAC_TEST_CHECKLIST.md`.

## Как устроено

- **Окно** (Electron) — только интерфейс. Закрытие окна или выход из приложения **не останавливает** сервер.
- **Фоновый сервер** (Node, тот же `server.js`, что и в веб-версии) запускается как служба `launchd` (LaunchAgent `com.moonkatty.aistudio.server`): перезапускается при сбое (KeepAlive), не мешает выключению Mac (завершается по SIGTERM за ≤5 с).
- **Один экземпляр**: второе окно приложения не открывается (фокус переходит на первое), второй сервер не запускается (проверка порта и `/api/health`).
- **Данные**: `~/Library/Application Support/MOONKATTY AI STUDIO/` (база `studio.db`, файлы, резервные копии, токен приложения). Журналы: `~/Library/Logs/MOONKATTY AI STUDIO/server.log`.
- **База**: SQLite через встроенный `node:sqlite` (формат файла тот же, что у веб-сервера с better-sqlite3 — можно перенести `studio.db`).
- **Секреты** (App Secret Meta, токены страниц) шифруются AES-256-GCM; ключ шифрования хранится в **связке ключей macOS** (Keychain, запись «MOONKATTY AI STUDIO»). Если Keychain недоступна — в файле `secret.key` (права 0600). В браузер и на GitHub Pages секреты не попадают.
- **Безопасность**: сервер слушает только `127.0.0.1`. Доступ к API — по сессии (логин/пароль) или по локальному токену приложения (заголовок, принимается только с 127.0.0.1).

## Установка

1. Скачайте `MOONKATTY-AI-STUDIO-<версия>-arm64-mac.zip` со страницы Releases репозитория (или соберите сами — см. ниже).
2. Откройте zip (Finder распакует его) и перетащите **MOONKATTY AI STUDIO.app** в папку «Программы».
3. **Сверьте контрольную сумму** до открытия: `shasum -a 256 ~/Downloads/MOONKATTY-AI-STUDIO-<версия>-arm64-mac.zip` — должна совпасть с файлом `.sha256` и `BUILD-INFO.txt` в релизе. Не совпадает — не открывайте.
   Первый запуск. Приложение **не подписано Apple Developer ID** (платная опция, 99 USD/год, не покупалась), поэтому macOS заблокирует его. Разрешайте только это приложение и только после сверки суммы, штатным путём Apple:
   - нажмите на приложение правой кнопкой (или Control-клик) → **Открыть** → **Открыть**; или
   - если macOS 15+ показывает только «Готово/Переместить в корзину»: **Системные настройки → Конфиденциальность и безопасность** → внизу «MOONKATTY AI STUDIO заблокировано…» → **Всё равно открыть** → введите пароль.
   Это нужно сделать один раз. Мы не рекомендуем отключать Gatekeeper или снимать атрибуты карантина вручную.
4. Откроется экран проверки компонентов: сервер, база данных, ключ шифрования, Ollama, фоновая служба. Если сервер не запущен и включено «Запускать сервер автоматически при открытии» — он запускается сам; иначе нажмите **Запустить сервер**. Затем откроется панель.
5. При первом входе создайте администратора (логин и пароль ≥ 8 символов). Дальше окно приложения входит автоматически по локальному токену.

### Автозапуск при входе в систему

Меню **Сервер → Запускать сервер при входе в систему** (или галочка на экране проверки). Включено — файл службы лежит в `~/Library/LaunchAgents/com.moonkatty.aistudio.server.plist`, и сервер со всеми расписаниями и агентами стартует после входа в macOS, даже без открытия окна. Выключено — служба загружается только когда вы открываете приложение. macOS может показать уведомление «Добавлен объект входа» — это нормально.

### Ollama (локальная модель)

```bash
brew install ollama        # или https://ollama.com/download
ollama serve               # или приложение Ollama
ollama pull qwen3:8b
```
Приложение проверяет `http://127.0.0.1:11434/api/tags`. Если Ollama нет — агенты, которым нужна модель (News, Content и др.), ставят задачи в статус **«Заблокировано»** с причиной; ничего не имитируется. Агенты Analytics, Publishing, Community выполняют свои действия без модели.

### OpenCode (задачи по коду) — выключен по умолчанию

Папка — не песочница, поэтому OpenCode по умолчанию **отключён**: такие задачи получают статус «Заблокировано: OpenCode отключён». Включение — на свой риск, вручную: в `~/Library/Application Support/MOONKATTY AI STUDIO/desktop.json` добавить `"enableOpenCode": true` и перезапустить сервер. Тогда задача выполняется только после кнопки «Разрешить OpenCode», через `sandbox-exec` (запрет записи вне папки задачи и чтения базы/ключей/`~/.ssh`/Keychains; сеть открыта; профиль не проверен на Mac — см. `docs/SECURITY_AUDIT.md`).

## Доступ с телефона

Только через Tailscale (см. `docs/CONNECT_MAC.md`): сервер слушает 127.0.0.1, а `tailscale serve --bg 8787` публикует его внутри вашей приватной сети tailnet по HTTPS. Сервер отвечает только на разрешённые имена хоста (защита от DNS rebinding): добавьте имя в `desktop.json` — `"allowedHosts": ["<имя-mac>.<tailnet>.ts.net"]` — и перезапустите сервер (меню Сервер → Остановить, затем открыть приложение). Не открывайте порт в интернет. На телефоне вход по логину и паролю.

## Обновление

- Приложение при запуске проверяет релизы закреплённого репозитория через HTTPS GitHub API и предлагает открыть страницу релиза, только если в нём есть архив и `.sha256`, совпадающий с digest GitHub. Ничего не скачивается и не устанавливается автоматически.
- Чтобы обновить: закройте приложение → замените `MOONKATTY AI STUDIO.app` в «Программах» новой версией → откройте. Сервер обновится при следующем открытии (служба перерегистрируется на новый путь). Данные в Application Support не затрагиваются.
- Вручную: меню **MOONKATTY AI STUDIO → Проверить обновления…**.

## Удаление (без потери данных)

1. Меню **Сервер → Остановить фоновый сервер**, снимите галочку автозапуска.
2. Закройте приложение и перетащите его из «Программ» в Корзину.
3. Удалите службу, если осталась: `launchctl bootout gui/$(id -u)/com.moonkatty.aistudio.server; rm -f ~/Library/LaunchAgents/com.moonkatty.aistudio.server.plist`
4. Данные остаются в `~/Library/Application Support/MOONKATTY AI STUDIO/` — их можно сохранить или скопировать. Полное удаление данных (необратимо): удалить эту папку, `~/Library/Logs/MOONKATTY AI STUDIO/` и запись «MOONKATTY AI STUDIO» в «Связке ключей».

## Сборка самостоятельно

- **На Mac (рекомендуется, даёт .dmg)**: `git checkout feat/macos-app && ./scripts/build-mac.sh` — нужен только Node.js 20+; результат в `dist/`.
- **На Linux** (так собран текущий релиз): `scripts/package-mac-on-linux.sh` — .app + .zip с ad-hoc подписью (rcodesign); .dmg на Linux не собирается.
- **GitHub Actions** (macos-14, arm64): шаблон `deploy/build-mac.yml.example`. Чтобы включить, нужен токен с правом **Workflows: Read and write только для репозитория moonkatty-ai-studio** (fine-grained PAT) — или добавьте файл `.github/workflows/build-mac.yml` через веб-интерфейс GitHub.

## Почему Electron

| Вариант | Сборка с Linux | Плюсы | Минусы |
|---|---|---|---|
| **Electron** (выбран) | да (.app/.zip; .dmg — только на Mac) | тот же код сервера; сервер запускается официальным Node 24 (встроенный `node:sqlite`, без нативных модулей); fuses закрывают RunAsNode | размер ~380 МБ |
| Tauri | нет (нужен Mac/Xcode для macOS-сборки) | маленький размер | нужен отдельный Node-sidecar для сервера, Rust-тулчейн; сборка только на Mac |
| WKWebView (Swift) | нет | нативно, мало весит | нужен Xcode; отдельная кодовая база |

## Стоимость

Бесплатно: Electron, electron-builder, rcodesign, Ollama, Tailscale (личный план), GitHub Releases. Опционально и платно: Apple Developer Program ($99/год) — даёт подпись и нотаризацию, убирает предупреждение Gatekeeper и делает возможным автообновление. Ничего не куплено.

## Что проверить на Mac (не проверено при сборке)

- Приложение открывается через «Открыть»/«Всё равно открыть»; иконка в Dock; меню на русском.
- Служба launchd регистрируется, сервер работает после закрытия окна, перезапускается после `kill -9`, автозапуск при входе включается/выключается.
- Ключ создаётся в Keychain (macOS может спросить разрешение «MOONKATTY AI STUDIO хочет использовать связку ключей» — нажмите «Разрешить всегда»).
- Mac выключается без задержек при работающем сервере.
