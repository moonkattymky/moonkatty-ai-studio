# 3. UI Алекса

Заголовок: **MOONKATTY AI CONTROL — ALEX**. Тот же премиальный тёмный TIDAL-стиль MOONKATTY, RU по умолчанию (EN/UK опц.). Отдельная оболочка `alex.html`/роут-набор; **12 экранов владельца не меняются** — выбор оболочки по роли из `/api/me`. Нижняя навигация: Главная · Задачи · Агенты · 3D · Ещё (остальные разделы).

| # | Раздел | Содержимое | Действия | API |
|---|---|---|---|---|
| 1 | Games Dashboard | карточки игр (баннер, ветка, последний билд, тесты ✓/✗), активные задачи, ожидают approve | открыть проект, новая задача | `GET /api/game/dashboard` |
| 2 | Игровые проекты | список allowlist (moonkatty-game, Horizons, будущие), ветки (protected помечены замком, только чтение) | создать рабочую ветку | `GET /api/game/projects`, `/:id/branches`, `POST /:id/branches` |
| 3 | Game AI Agents | только game-агенты (Game Dev, QA, 3D DESIGN), статус, загрузка | дать задачу | `GET /api/game/agents` |
| 4 | Задачи и очередь | общая игровая очередь: автор (аватар OWNER/ALEX), прогресс, ветка, lock; фильтры «мои/все» | создать, стоп (свою), retry | `GET/POST /api/game/tasks`, `/:id/cancel`, `/:id/retry` |
| 5 | 3D Studio | Blender по vetted-шаблонам, версии, превью рендера | создать сцену/рендер (лимит) | `/api/game/3d/*` |
| 6 | Тестирование | наборы тестов проекта, последние прогоны, логи | запустить тесты | `POST /api/game/tests/run` |
| 7 | Игровые файлы и версии | дерево файлов ветки (read-only), diff коммитов, история | просмотр, скачать артефакт | `GET /api/game/files`, `/commits` |
| 8 | Результаты и отчёты | итоги задач, diff, скриншоты, отчёты тестов | **«Отправить на утверждение»** | `POST /api/game/releases` |
| 9 | Игровые уведомления | готово/упало/approve/отклонено/задача остановлена владельцем | отметить прочитанным | `GET /api/game/notifications` |
| 10 | Личные настройки | язык, passkey, активные сессии (свои), выход | добавить passkey, выйти везде | `/api/me/*` |

Состояния: loading / empty / error / 403 («Нет доступа — обратитесь к владельцу»). Запрещённые разделы владельца в навигации отсутствуют, а прямой URL отдаёт 403.

Для OWNER добавляется (в существующие экраны, отдельной вкладкой «Пользователи»): список пользователей, роль, сессии, «Отозвать сейчас», allowlist игр, очередь релизов на approve, audit. Это изменение владельческих экранов планируется отдельным этапом и требует согласования.

Статический макет HTML в этом этапе не делаем (опционально, следующий шаг).
